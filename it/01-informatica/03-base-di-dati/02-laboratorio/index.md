# Laboratorio

Materiale del modulo pratico del corso di Basi di Dati. Contiene il progetto *Collectors*: un database per la gestione di collezioni di dischi, sviluppato con MySQL e corredato da un'interfaccia grafica realizzata con SvelteKit ed Electron. Il progetto comprende analisi del dominio, progettazione concettuale con diagramma ER, traduzione al modello logico relazionale, implementazione fisica con tabelle, trigger, stored procedure e funzioni, e una suite di query per le principali funzionalità richieste.
