Riassunto e lista di protocolli utili da sapere

| Livello OSI                       | Protocollo     | Descrizione                                                                                           |
| --------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------- |
| **Livello 7** (Applicazione)      | HTTP/HTTPS     | HyperText Transfer Protocol; usato per trasferire pagine web su Internet. HTTPS è la versione sicura. |
|                                   | FTP/SFTP       | File Transfer Protocol; utilizzato per trasferimento file. SFTP è la versione sicura (usa SSH).       |
|                                   | SMTP           | Simple Mail Transfer Protocol; protocollo per l'invio di email.                                       |
|                                   | POP3/IMAP      | Protocollo per recupero di email; POP3 scarica le email, IMAP le sincronizza con il server.           |
|                                   | DNS            | Domain Name System; traduce nomi di dominio in indirizzi IP.                                          |
|                                   | Telnet/SSH     | Protocolli per accesso remoto a sistemi; SSH è crittografato, Telnet non lo è.                        |
|                                   | DHCP           | Dynamic Host Configuration Protocol; assegna dinamicamente indirizzi IP ai dispositivi.               |
|                                   |                |                                                                                                       |
| **Livello 5** (Sessione)          | SMB            | Server Message Block; protocollo per la condivisione di file e stampanti in reti locali.              |
|                                   | PPTP/L2TP      | Point-to-Point Tunneling Protocol e Layer 2 Tunneling Protocol; usati per reti VPN.                   |
|                                   |                |                                                                                                       |
| **Livello 4** (Trasporto)         | TCP            | Transmission Control Protocol; fornisce connessione affidabile tra dispositivi.                       |
|                                   | UDP            | User Datagram Protocol; invia pacchetti senza conferma, meno affidabile ma più veloce.                |
|                                   | SCTP           | Stream Control Transmission Protocol; simile a TCP, ma con più flessibilità per alcuni usi.           |
|                                   |                |                                                                                                       |
| **Livello 3** (Rete)              | IP             | Internet Protocol; instrada pacchetti tra reti e dispositivi.                                         |
|                                   | ICMP           | Internet Control Message Protocol; usato per inviare messaggi di errore e di controllo.               |
|                                   | ARP            | Address Resolution Protocol; traduce indirizzi IP in indirizzi MAC.                                   |
|                                   | RIP, OSPF, BGP | Protocolli di routing; usati per definire i percorsi per i dati in reti IP.                           |
|                                   | NAT            | Traduce IP privati in IP pubblici, permettendo la comunicazione con l'esterno della rete              |
|                                   |                |                                                                                                       |
| **Livello 2** (Collegamento Dati) | Ethernet       | Protocollo di comunicazione per reti LAN cablate.                                                     |
|                                   | PPP            | Point-to-Point Protocol; usato per connessioni punto a punto, spesso su reti WAN.                     |
|                                   | Wi-Fi (802.11) | Standard per reti locali wireless (LAN).                                                              |
|                                   | Token Ring     | Protocollo LAN usato principalmente in reti locali IBM.                                               |
|                                   |                |                                                                                                       |
| **Livello 1** (Fisico)            | DSL, ADSL      | Digital Subscriber Line; protocolli per connessioni Internet ad alta velocità su linea telefonica.    |
|                                   | ISDN           | Integrated Services Digital Network; vecchio standard per voce e dati su linea telefonica.            |
